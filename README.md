# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
1. Open Autodesk Fusion and start a new sketch on the bottom XY plane.
2. <img width="537" height="672" alt="Screenshot 2026-11-16 222808" src="https://github.com/user-attachments/assets/daa727d9-4cfa-4ca9-bc7c-8505d06eabc5" />

3. Draw a square using the rectangle tool for the top surface and finish the sketch.
4. <img width="272" height="475" alt="Screenshot 2026-11-16 015558" src="https://github.com/user-attachments/assets/247c5841-266a-4763-a0e5-bcd95466ee82" />

5. Use the extrude command to pull the square upward to give the table top its thickness.
6. <img width="665" height="711" alt="Screenshot 2026-11-16 020756" src="https://github.com/user-attachments/assets/ec8a1ac4-1d7a-4962-a0a9-bd9083f95fd4" />

7. Rotate the view to the bottom and create a new sketch on the underside of the top.
8. Sketch four small squares of equal size at each corner for the legs.
9. Select all four corner squares and extrude them downward to the required leg height.
10. Keep the operation set to Join so the legs and top become one single body.
11. <img width="717" height="260" alt="Screenshot 2026-11-16 223349" src="https://github.com/user-attachments/assets/44f63a3d-1d79-4163-aa46-aafbd1388642" />

12. Select the chamfer tool from the modify panel and click the four top outer edges.
13. <img width="737" height="701" alt="Screenshot 2026-11-16 223451" src="https://github.com/user-attachments/assets/a4f81173-cd07-4d55-a439-178e699b234d" />

14. Enter a small chamfer value to create the angled edge around the top and click OK.
15. <img width="480" height="263" alt="Screenshot 2026-11-16 223618" src="https://github.com/user-attachments/assets/e26b0ff8-6ce2-4489-be52-dd46240bbf4c" />

16. Open the appearance settings, apply a dark grey material to the body, and save the file.
